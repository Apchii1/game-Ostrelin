Skyline Sprint

Полностью готовый 2D-платформер на Canvas без библиотек: 4 уровня, монеты, ловушки, финальная цель, экран победы и повторный запуск.

Управление

  • A / D или ← / → — движение
  • W / ↑ / Space — прыжок
  • R — перезапуск уровня
  • Enter — начать / продолжить
  • M — звук вкл/выкл

MVP по методике пары

  1. Разделение проекта на папки css/, js/, assets/.
  2. Есть core-loop: движение → сбор монет → финиш.
  3. 4 уровня с ростом сложности.
  4. Проверяемое состояние победы/проигрыша.
  5. README c pipeline: setup → build → verify → commit.
